# Deepak Kumar - Research Portfolio

A modern, responsive portfolio website showcasing Deepak Kumar's research work, publications, and technical expertise in AI/ML, LLM inference optimization, and high-performance computing.

## 🚀 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive**: Fully responsive across all devices
- **Research-Focused**: Highlights research publications, projects, and technical contributions
- **Interactive**: Smooth scrolling navigation and animated components
- **Dark Mode**: Built-in dark mode support
- **Performance Optimized**: Fast loading with Next.js and optimized assets

## 🛠️ Tech Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript
- **Deployment**: Vercel-ready

## 📋 Sections

1. **Hero**: Introduction and call-to-action
2. **About**: Background, education, and research interests
3. **Research**: Current research focus and contributions
4. **Publications**: Research papers and technical writing
5. **Experience**: Professional work experience
6. **Projects**: Recent projects and implementations
7. **Skills**: Technical skills and expertise
8. **Contact**: Contact information and form

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd portfolio
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📝 Customization

### Personal Information
Update the following files with your information:
- `components/Hero.tsx` - Hero section content
- `components/About.tsx` - Personal background and education
- `components/Experience.tsx` - Work experience
- `components/Projects.tsx` - Project details
- `components/Skills.tsx` - Skills and expertise
- `components/Contact.tsx` - Contact information

### Styling
- Modify `tailwind.config.js` for color schemes and theme customization
- Update `app/globals.css` for global styles
- Customize component styles in individual component files

### Content
- Add your publications to `components/Publications.tsx`
- Update research focus in `components/Research.tsx`
- Modify project details in `components/Projects.tsx`
